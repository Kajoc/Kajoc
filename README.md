## Projects

- [Customer Churn Analysis Dashboard](https://github.com/Kajoc/Customer-Churn-Analysis-Project): Analysis of over 7k records of customer churn data to uncover insights on customer churn behavior across demographics, membership patterns, products and services.
- [Bellabeat Marketing Analysis: Smart Device Usage Insights](https://github.com/Kajoc/BellaBeat-Case-Study-with-Python-powerBI): Analyzed Fitbit data from 33 users using Python and Power BI to uncover activity, sleep, and heart rate trends. Found users average 8.5K steps but are 71% sedentary, with strong sleep efficiency (93.7%) but inconsistent duration. Delivered high-level marketing recommendations for Bellabeat's app strategy.
- [Sports Entertainment Tickets Data Cleaning Project](https://github.com/Kajoc/Sports-Entertainment-Tickets-Data-Cleaning-Project): An SQL data cleaning project with MySQL that transforms a raw, messy ticketing dataset into an analysis-ready table with consistent types, resolved duplicates, and standardized dates. The dataset simulates ticket sales across sports and entertainment events — covering orders, customers, venues, pricing, payment, attendance, and post-event feedback.
  - [Sample Superstore Sales & Profit Analysis](https://github.com/Kajoc/Sample-superstore-case-study): This project covers the analysis of sales and profit performance across product categories and sub-categories, shipping modes, and geographic regions using Google Sheets for cleaning, validation and standardization of the dataset and then Tableau for visualizations. The goal is to uncover actionable insights and provide recommendations to improve profitability and business performance.
